## Current Status

| Area                                                             | Status          | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Repository and documentation                                     | **In progress** | This README defines scope and intended architecture, and marks what is implemented.                                                                                                                                                                                                                                                                                                                                                                                      |
| Monorepo scaffolding (`apps/web`, `apps/api`, `packages/shared`) | **Implemented** | pnpm workspaces; shared TypeScript, ESLint and Prettier config.                                                                                                                                                                                                                                                                                                                                                                                                          |
| Shared package (`packages/shared`)                               | **Implemented** | Zod schemas with inferred types: health and readiness responses, auth requests, the public user, the error response shape, plus a Zod error formatter.                                                                                                                                                                                                                                                                                                                   |
| API skeleton (Fastify)                                           | **Implemented** | Validated env config, `GET /health` (liveness), `GET /ready` (readiness, checks the database), graceful shutdown.                                                                                                                                                                                                                                                                                                                                                        |
| Web skeleton (Next.js)                                           | **Implemented** | Home page that shows the API health status (fetched server-side) and links to log in, sign up or the profile.                                                                                                                                                                                                                                                                                                                                                            |
| Local infrastructure (Docker Compose)                            | **Implemented** | PostgreSQL 18 and Redis 8 for local development. The API connects to Postgres; nothing uses Redis until Stage 7.                                                                                                                                                                                                                                                                                                                                                         |
| CI (GitHub Actions)                                              | **Implemented** | Typecheck, lint, format check, tests (with a PostgreSQL 18 service container), API build and web build on PRs and pushes to `main`.                                                                                                                                                                                                                                                                                                                                      |
| Tests (Vitest)                                                   | **Implemented** | Unit tests, plus API integration tests (auth routes, sessions, `/ready`, the unique email index) that run against a separate test database (`diffcraft_test`, migrated automatically before the tests; skipped if `TEST_DATABASE_URL` is unset). No coverage figures are claimed.                                                                                                                                                                                        |
| Database layer (Drizzle)                                         | **Implemented** | Drizzle schema and migrations for the `users` and `sessions` tables, `GET /ready`. The rest of the schema in [database.md](database.md) is still a proposal.                                                                                                                                                                                                                                                                                                             |
| Authentication                                                   | **Implemented** | Register, login, logout and me (`/api/v1/auth/*`), with server-side sessions in HttpOnly cookies.                                                                                                                                                                                                                                                                                                                                                                        |
| Web pages (sign-up, login, profile)                              | **Implemented** | Sign-up, login and profile pages, plus logout.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Deployment (Vercel + Render + Neon)                              | **Implemented** | Web on Vercel, API on Render, PostgreSQL on Neon. See [deployment.md](deployment.md).                                                                                                                                                                                                                                                                                                                                                                                    |
| Workspaces and membership                                        | **In progress** | Done: the `workspaces` and `workspace_members` tables, the `requireWorkspaceRole` guard, the workspace endpoints (`/api/v1/workspaces`), member management with the last-owner rule (`/members`), and the web pages for both (`/workspaces`, `/workspaces/[workspaceId]`). Invitations are next.                                                                                                                                                                         |
| Reviews and diff ingestion                                       | **Implemented** | The diff parser, the `reviews` and `review_files` tables, the review endpoints (create, list with filters and cursor pagination, get, edit, close/reopen, delete, files, per-file hunks) and the web pages (`/workspaces/[workspaceId]/reviews`, `/reviews/new`, `/reviews/[reviewNumber]`). Revisions move to Stage 5.                                                                                                                                                  |
| Code diff viewer                                                 | **Implemented** | The "Files changed" page (`/workspaces/[workspaceId]/reviews/[reviewNumber]/files`): unified and split views, a file sidebar, syntax highlighting (Shiki, on the server), word-level changes, line anchors and deep links, and "Load diff" for large files.                                                                                                                                                                                                              |
| Comments and threads                                             | **In progress** | Done: the `comment_threads` and `comments` tables, the thread endpoints (`/reviews/:reviewNumber/threads`) with shared permission rules, and the web UI: line comments in the unified and split diff views, replies, edit, delete, resolve/reopen, a Conversation section on the review page, and suggested-change blocks (shown as a diff, copyable, and downloadable as a patch checked with `git apply`). Still to come in Stage 5: revisions and outdated detection. |
| Approvals                                                        | **Implemented** | Stage 6. Reviewer assignment, approve / request changes, merge when the workspace's rules pass (required approvals, all threads resolved), review history; API under `/reviews/:reviewNumber` (`state`, `reviewers`, `decisions`, `merge`, `events`) and `/rules`; web: status and decision badges, merge box, reviewers panel, "Your review" box, history timeline, "Waiting for my review" and Merged list filters, approval rules card on the workspace page.         |
| Real-time collaboration (Socket.IO)                              | Planned         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| AI analysis worker (BullMQ + LLM provider)                       | Planned         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Application Dockerfiles                                          | Planned         | Only local Postgres and Redis run in Docker so far.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| OpenAPI documentation                                            | Planned         | To be generated from Zod route schemas.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| GitHub integration and OAuth                                     | Planned         | Stage 10.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Email and search                                                 | Planned         | Stage 11.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## Development Roadmap

| Stage                                | Scope                                                                                                                                                                                                                                                                                                                                                                                   | Status          |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| **0. Foundation**                    | pnpm monorepo; shared TypeScript, ESLint, Prettier and Vitest config; shared package; API and web skeletons; local Docker Compose; CI.                                                                                                                                                                                                                                                  | **Implemented** |
| **1. Database and auth**             | Drizzle schema and migrations; database connection; `/ready` probe; registration, login and sessions; sign-up, login and profile pages; free-tier deployment (Vercel, Render, Neon).                                                                                                                                                                                                    | **Implemented** |
| **2. Workspaces and roles**          | Workspaces, membership and invitations; role-based authorization guards.                                                                                                                                                                                                                                                                                                                | **In progress** |
| **3. Reviews and diff ingestion**    | Review creation from patch upload; the diff parser (`packages/shared/src/diff`); the `reviews` / `review_files` tables; review endpoints with cursor pagination; changed-file list; review web pages.                                                                                                                                                                                   | **Implemented** |
| **4. Diff viewer**                   | Unified and side-by-side diff views; file navigation; stable line references; syntax highlighting (Shiki) and intra-line (word-level) diff highlighting.                                                                                                                                                                                                                                | **Implemented** |
| **5. Comments and threads**          | Review revisions (moved from Stage 3; needed for outdated detection); line-anchored comments, replies, resolution and outdated detection; suggested-change blocks in comments, shown as a diff and downloadable as a patch the author can apply with `git apply`.                                                                                                                       | **In progress** |
| **6. Approvals and lifecycle**       | Reviewer assignment; approve / request changes; status recomputation; review history; configurable approval rules per workspace (required number of approvals, require all threads resolved), evaluated by a pure shared function.                                                                                                                                                      | **Implemented** |
| **7. Real-time**                     | First use of Redis: Socket.IO with session auth and rooms; emit-after-commit; presence (Redis TTL keys); notifications; Socket.IO Redis adapter.                                                                                                                                                                                                                                        | Planned         |
| **8. AI analysis**                   | Job model; BullMQ queue (on Redis) and worker; provider adapter; context building and redaction; schema-validated findings; retries; findings UI; helpful / not-helpful feedback on findings and a fixed evaluation set of patches to measure prompt and model changes; per-workspace AI settings (enabled categories, minimum severity, opt-out), admin only.                          | Planned         |
| **9. Hardening and deployment**      | Rate limiting, security headers, end-to-end tests, Dockerfiles, multi-instance deployment, observability; custom domain (also required for sending email).                                                                                                                                                                                                                              | Planned         |
| **10. GitHub integration and OAuth** | Sign in with GitHub and Google (OAuth 2.0 authorization code flow with PKCE and state, linked to existing accounts by verified email, keeping server-side sessions); a GitHub App to import a pull request as a review, post AI findings back as review comments and commit accepted suggestions to the PR branch; webhooks with HMAC signature verification and idempotent processing. | Planned         |
| **11. Email and search**             | Transactional email (email verification, password reset, invitation emails, review notifications and a daily digest with unsubscribe links) sent through a background job; Mailpit for local development; Postgres full-text search across reviews and comments.                                                                                                                        | Planned         |

- Audit log export.
- GitLab integration.
- SSO (SAML / OIDC).
